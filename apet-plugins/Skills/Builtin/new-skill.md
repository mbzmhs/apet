# 新建技能

帮助用户把一个可复用的流程沉淀为 APet 技能。技能 = 一个文件夹里的 `SKILL.md`(YAML frontmatter + Markdown 正文),目录结构兼容 Codex 技能。

## 目录与格式约定

- 用户技能位置:`~/.apet/skills/<技能名>/SKILL.md`(技能名即文件夹名,建议英文短横线小写)
- frontmatter 字段:
  - `name`:技能名(展示与调用名)
  - `description`:给模型看的**触发说明**——什么情况下应加载本技能,写得越具体越容易被正确选用
- 正文:Markdown,写清该技能的步骤、约束、输出要求;可引用同目录的脚本/参考文件(相对路径),参考 Codex 技能的 `scripts/`、`references/` 子目录组织方式
- 内置技能(如本技能)随应用发布,存放在应用的内置资源中,不出现在用户目录,也不可编辑删除

## 创建步骤

1. 与用户确认四件事:技能名、这个技能解决什么问题、什么场景应触发它、具体步骤与期望输出
2. 起草 `SKILL.md`:frontmatter 的 description 写清触发条件;正文用有序步骤描述流程,含检查点和失败处理
3. 交付方式(按用户偏好二选一):
   - 让用户在 **设置 → 内置插件 → 技能 → 新建** 中粘贴保存(把最终 SKILL.md 内容整理好交给用户)
   - 或在获得文件写入授权后,直接把文件写到 `~/.apet/skills/<技能名>/SKILL.md`
4. 保存后让用户在聊天框输入 `$skills` 验证清单,再让模型实际调用 skill 工具做一次冒烟

## 质量要点

- description 里写"何时用 / 何时不用"(Codex 风格),避免被误触发
- 正文步骤保持原子性:每步一个动作、一个检查点
- 需要参数的技能,在正文开头列出"调用前需要收集的信息"
